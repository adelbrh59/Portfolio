Le programme Python que j’ai réalisé est une calculatrice simple. Il permet d’effectuer des opérations de base (+, -, *, /) 
entre deux nombres. 
Danss ce programme, on peut voir l’utilisation de variables, de conditions (if, elif, else) et d’une logique permettant de choisir l’opération à effectuer selon le signe entré par l’utilisateur.
