Le programme Python que j’ai réalisé est un petit jeu du nombre mystère.

L’ordinateur génère un nombre aléatoire et le joueur doit essayer de le trouver.

À chaque tentative,le programme indique si le nombre proposé est trop petit ou trop grand. Dans ce programme, 
on peut voir l’utilisation de variables, de conditions, d’une boucle et d’une logique permettant de guider le joueur jusqu’à trouver le bon nombre.ojet utilise des variables, 
une boucle, des conditions et le module.
